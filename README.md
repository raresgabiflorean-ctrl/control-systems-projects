# control-systems-projects
A collection of control systems projects developed using MATLAB, Simulink and Simscape, focusing on system modeling, controller design, simulation, performance analysis and robustness.

## Projects

### 1. Cruise Control System

A cruise control system modeled and controlled using MATLAB and Simulink.

**Main topics:**
- Mathematical modeling
- Transfer function derivation
- Open-loop system analysis
- PI controller design and implementation
- Closed-loop performance analysis
- Robustness analysis

---

### 2. Two-Tank Level Control System

A coupled two-tank level control system developed and analyzed using MATLAB and Simulink.

**Main topics:**
- Mathematical modeling and transfer function derivation
- Open-loop system analysis
- PI controller design and implementation
- Step response and control signal analysis
- Gain and phase margins
- Linearity verification
- Parameter variations and flow disturbances
- Actuator saturation
- Integrator windup
- Robustness analysis

---

### 3. Inverted Pendulum Control

An inverted pendulum control system developed using MATLAB and Simulink, including both classical and modern control approaches.

**Main topics:**
- Mathematical modeling
- System linearization
- State-space representation
- Controllability and observability analysis
- PID controller design
- LQR controller design
- PID vs. LQR performance comparison
- Robustness and disturbance analysis

---

### 4. Electromechanical System Modeling and Control

An electromechanical system modeled using Simscape and controlled through a closed-loop PI controller.

**Main topics:**
- Electrical and mechanical physical modeling
- Open-loop system testing
- Feedback control implementation
- PI controller tuning
- Disturbance rejection
- Robustness to variations in resistance, inertia and load

## Tools & Technologies

- MATLAB
- Simulink
- Simscape
- Control System Toolbox
- System Identification Toolbox

## About

These projects were developed as part of my preparation and practical work in control systems and automation engineering.

The repository focuses on applying theoretical concepts to simulation and control problems using MATLAB, Simulink and Simscape.
